# The Wild Oasis Hotel Management System

A practice project built while learning React and Supabase. This hotel management application demonstrates modern React development practices and integration with a backend service.

## 🛠️ Technologies Used

- **React** - Frontend framework
- **Styled Components** - Styling
- **React Query** - Server state management
- **React Hook Form** - Form handling
- **Supabase** - Backend and database
- **React Router** - Navigation
- **Recharts** - Data visualization
- **React Hot Toast** - Toast notifications
- **React Icons** - Icon library

## ✨ Key Features

### Authentication & Authorization

- User authentication system
- Protected routes
- Role-based access control
- User profile management

### Cabin Management

- CRUD operations for cabins
- Image upload functionality
- Cabin filtering and sorting
- Responsive cabin gallery

### Booking System

- Comprehensive booking management
- Check-in/check-out functionality
- Booking status tracking
- Guest information management

### Dashboard & Statistics

- Real-time statistics
- Sales charts and graphs
- Occupancy rates
- Important KPIs visualization

### Settings Management

- Application settings configuration
- Breakfast price management
- Min/max nights per booking
- Hotel policies management

## 🏗️ Architecture & Implementation

- Custom hooks for business logic
- Context API for global state
- React Query for server state
- Optimistic updates for better UX
- Responsive design
- Dark/Light theme support
- Form validation
- Error boundaries
- Loading states and skeletons

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up Supabase and configure environment variables
4. Run development server: `npm run dev`

## 🔐 Environment Variables

Create a `.env` file with:

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_KEY=your_supabase_anon_key
```
